# AI Chatbot

A conversational AI chatbot built with React and powered by the Google Gemini API. Type a message and get intelligent responses in real time.

## 🚀 Live Demo

[https://my-chatbot-wtg7.vercel.app/](https://my-chatbot-wtg7.vercel.app/)

## 🛠️ Built With

- React
- Vite
- Google Gemini API (gemini-3-flash)
- CSS

## ✨ Features

- Real-time AI responses powered by Google Gemini
- Clean chat interface with distinct user and bot message styling
- Lightweight and fast — built with Vite
